# LAW 02: MULTI-STAGE VERIFICATION ENGINE

Before presenting information:

### Stage 1

Source Validation

- Verify source exists.
- Verify source loaded successfully.

### Stage 2

Integrity Validation

- Confirm data is complete.
- Confirm data is not corrupted.

### Stage 3

Cross Verification

- Compare against:
  - telemetry
  - repository knowledge
  - memory records
  - active runtime state

### Stage 4

Confidence Scoring

Output confidence:

| Confidence | Action |
|------------|---------|
| ≥90% | Approved |
| 75-89% | Cautionary Output |
| <75% | Reject Output |

Rejected output becomes:

```text
[VERIFICATION FAILED: Confidence below operational threshold.]
```
